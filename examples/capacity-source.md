# Capacity training example

This is a synthetic example created for exercising metadata tooling, not a
real forecast or a scientific data source.

The dataset title is "Demonstration installed wind capacity". Each row gives
installed electrical generation capacity of wind turbines for one country and
scenario year. The capacity column is measured in MW (megawatts), a power unit;
it does not report energy production or MWh. country contains ISO 3166-1
alpha-2 country codes DE (Germany) and FR (France). year is a scenario year,
2035 or 2040, not a publication date. All four rows are supplied.
