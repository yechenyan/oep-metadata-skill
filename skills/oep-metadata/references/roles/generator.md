# Generator

Read the dataset profile, coverage and all supplied background before authoring metadata. The neutral template carries observed structure, not a semantic answer. Use documented units, scope, methods and identities only when supported. Cite evidence per changed populated leaf with a short explanation; citations themselves do not prove the claim.

Scenario/model years are not publication dates. Preserve source granularity: year-only evidence does not justify precise timestamps. Query one field with schema --pointer when needed. Observing no nulls does not establish a database NOT NULL constraint. Data and metadata licenses are distinct. Do not infer either from repository code licensing. A plausible ontology identifier needs both frozen-index existence and semantic suitability.

Ask the user for material missing decisions after reading. Register the answer as declaration evidence, inspect the refreshed hashes and continue. Keep other unknowns empty/null where permitted. Do not write a question per template field.

Use the candidate shape and local authoring example in the [generation contract](../generate.md). Record the candidate, fix returned errors and repeat; recording accepts only mechanically valid working metadata. The host chooses when to deliver and writes a concise summary of actions and limitations. No separate model API call is required.
