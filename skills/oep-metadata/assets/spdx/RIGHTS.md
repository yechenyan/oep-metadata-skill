# SPDX factual identifier index

`licenses.json` is the unchanged SPDX License List 3.27.0 identifier index from the versioned source recorded in `provenance.json`. It contains identifiers, names, deprecation flags and reference URLs; individual license texts are not bundled here. SPDX documents the generated JSON data as a supported consumption format in the upstream usage documentation linked in provenance.

No standalone repository license grant was found at the tagged source, so this package does not invent one or claim that a license listed in the index licenses the index itself. Names and links retain their original attribution. Identifier membership does not establish licensing authority over user data.
